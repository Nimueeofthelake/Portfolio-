Reinforcement Learning

Reinforcement learning is primarily used when the surrounding environment is changing or the agent is learning through trial and error. The agent primarily learns by interacting with the environment. The agent is the main decision maker in this system. The environment is the main thing the agent interacts with. The current situation of the agent is represented by the initial state. From that state, the agent will decide its actions, which causes the environment to become a new state. The outcome of the actions will affect the reward the agent receives. The reward can be positive, negative, or neutral. After many trial-and-error interactions with the environment, the actions can determine a policy for the agent to follow.

A major reinforcement learning algorithm is Q-learning. Q-learning is a value-based reinforcement learning algorithm that learns the quality (the Q-value) of performing a certain action to maximize long-term rewards. This can be represented by using a Q-table, where rows represent states, the columns represent possible actions, and entries are numerical estimates of an action's quality for each state-action pair. What the Q-values estimate is the expected overall reward an agent could possibly get by taking a particular route.

Q(s,a) = Q(s,a) + [r + α max Q(s',a') - Q(s,a)]
