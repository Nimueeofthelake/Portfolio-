Reinforcement Learning

Reinforcement learning is primarily used when the surrounding environment is changing or the agent is learning through trial and error. The agent primarily learns by interacting with the environment. The agent is the main decision maker in this system. The environment is the main thing the agent interacts with. The current situation of the agent is represented by the initial state. From that state, the agent will decide its actions, which causes the environment to become a new state. The outcome of the actions will affect the reward the agent receives. The reward can be positive, negative, or neutral. After many trial-and-error interactions with the environment, the actions can determine a policy for the agent to follow.

A major reinforcement learning algorithm is Q-learning. Q-learning is a value-based reinforcement learning algorithm that learns the quality (the Q-value) of performing a certain action to maximize long-term rewards. This can be represented by using a Q-table, where rows represent states, the columns represent possible actions, and entries are numerical estimates of an action's quality for each state-action pair. What the Q-values estimate is the expected overall reward an agent could possibly get by taking a particular route.

Q(s,a) = Q(s,a) + [r + α max Q(s',a') - Q(s,a)]

Evidence

A simple example where reinforcement learning would be present is in self-driving cars. The learning-to-drive strategies would be the main aspect of where reinforcement learning is present to improve the safety and efficiency of driving. The main way a self-learning agent learns is that the car's state is the observation of the surrounding area via its cameras and sensors to capture information about the current environment. From there, the car can select the action it can take based on the car's current policy, such as steering or acceleration. Based on the outcome of these actions, the car will receive a positive or negative feedback reward for staying in the lane, avoiding collisions, or a negative reward for a near miss or a move that breaks traffic safety.

Such an example can be seen in the "Learning to Drive in a Day" article by Alex Kendall et al., in the processes of the reinforcement learning of the Wayve self-driving car. The agent uses camera images, vehicle speed, and steering information to navigate the environment.

The agent can take actions by adjusting the steering angle and speed set point. The reward function for this agent is based on the GPS tracking error and the information the agent receives, including forward speed, as well as an episode terminated when the vehicle does not comply with traffic laws. The policy that the autonomous driving car utilizes is the strategy it uses to steer and control its speed while staying within the lane. The policy for this agent was developed using Deep Deterministic Policy Gradient (DDPG).
